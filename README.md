# Edexcel IAL Physics 学习系统 — 说明

- **学生端：https://equistaric.github.io/edx/**
- **教师端：https://equistaric.github.io/edx/teacher.html**

仓库：`equistaric/edx`（与 CIE 的 `equistaric/plan` 完全分开，互不影响）。
改动后运行 `./deploy.sh "说明"` 即可上线，1–3 分钟生效，网址不变。

刷题 + 自动批改 + 错题本 + 老师批改，一个网站。完全复刻 CIE 学习系统的逻辑，
但**数据库表、账号、本地缓存全部独立**（`edx_` 前缀），不会影响 CIE 那套的迭代。

## 和 CIE 版的区别

| | CIE 版 | 爱德思版 |
|---|---|---|
| 顶层维度 | Paper 1 / 2 / 4 | **Unit 1 / 2 / 4 / 5** |
| 每章套题 | 四册（按年份分） | **两套：选择题 / 大题** |
| 时间线 | 按考试日排期 | **不排期**，按章节自由刷 |
| 数据库 | `accounts`、`practice`… | **`edx_accounts`、`edx_practice`…** |
| 本地缓存 | `ial27w.*` | **`edxial.*`** |

题库：**1079 题**（选择题 536 + 大题 543），33 章，2746 张题图/答案图。
全部来自 2019–2025 真题，切片经过逐题校验（每道题都配有正确答案）。

## 第一次使用：初始化数据库（必做一次）

1. 打开 Supabase 控制台 → SQL Editor。
2. 把 `_private/setup_edx.sql` **整段粘贴进去 Run**（可重复运行，不会重置已有账号）。
3. 完成后即可登录。

初始账号见 `_private/账号密码.txt`：学生 `zzh / a123456`，教师 `teacher / a123456`。

> 与 CIE 用的是同一个 Supabase 项目，但所有表和函数都带 `edx_` 前缀，
> 前端通过 `config.js` 里的 `prefix: "edx_"` 调用，两套系统互不干扰。

## 学生怎么用

四个页签：**今天 · 刷题 · 复习 · 我的**

- **刷题**：顶部切 Unit 1/2/4/5 → 每章一张卡，两个格子：**选择题**、**大题**。
  - **选择题**：整套题图 + A/B/C/D，边做边存；「提交判分」立刻出分、逐题 ✓/✗，答错的自动进错题本；
    交卷后可在题图上手写批注（老师讲题用），点「📝 加笔记区」写过字的题进「复习 → 选择题批注」。
  - **大题**：进手写页，Apple Pencil / 鼠标书写（手指用于滚动），笔压粗细、四色、橡皮、撤销、双指缩放、图形识别。
    流程：写完 →「保存 · 看答案」（**自动展开该题的官方评分方案**，笔自动转红便于订正，可自评）→「下一题」→ 最后「提交整套」交给老师批改。
    保存后原答案锁定，之后写的算「批注层」，老师批改的是原答案。
- **复习**：选择题错题（复习模式、PDF 导出）、选择题批注、大题批注。
- **我的**：等级 / XP、统计、成就、班级榜、改密码。
- 记录存在账号里，换设备登录就有；没网先存本机，联网自动补传。

## 老师怎么用

- **刷题进度**：每个学生四个 Unit 的完成率、在线做题情况、错题数；点姓名展开热力图与薄弱考纲点；全班进度矩阵。
- **批作业**：学生「提交整套」后出现在待批列表 → 全屏批改，用 Apple Pencil 在学生手写上打 ✓✗ 写批语、打分、写评语，每题自动保存，学生端立刻可见。
- **讲题模式**：左边题目 + 老师板书，右边全班每个人这道题的手写答案，可置顶 / 排序 / 放大 / 拉到左边讲评。
- **做题结果**：选择题每题错误率、选项分布、答错名单、学生×题目矩阵；大题「谁写了」矩阵。
- **错题分析**：全班薄弱点排行、多人错的同一道题。
- **学生管理**：添加、改名 / 班级、重置密码、清空记录、删除。
